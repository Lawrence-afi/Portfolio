# Miracle Onukak — Portfolio

Static site with no dependencies and no build step.

## Run
Open `index.html` in a browser, or serve the folder:

    npx serve .

## Structure
- index.html: page markup
- assets/css/styles.css: all styles
- assets/js/script.js: contact form handler (demo only, connect a backend such as Formspree to deliver messages)
- assets/images/: profile photos and project screenshots

## Deploy
Upload the folder to Netlify, Vercel, GitHub Pages or any static host.
